# 0001. Видимость приватных полей груза

**Контекст.** Аудит (SEC-02) показал, что `GET /api/loads/:id` и список биржи отдают любому перевозчику и экспедитору заметки владельца (`notes`, в интерфейсе — «видны только вам»), имя клиента экспедитора (`clientName`) и контакты на точках маршрута.

**Решение.** Ответ формируется по отношению к грузу (`loadForViewer`, `src/server/services/load.service.ts`):

- владелец и администратор платформы — все поля;
- выбранный перевозчик (с момента принятия его ставки) — контакты и примечания точек, имя клиента; без заметок владельца;
- остальные перевозчики, экспедиторы, проигравшие торги — без заметок, имени клиента, контактов и примечаний точек.

Биржа (`listLoads`, scope `marketplace`) не отдаёт `notes` и `clientName`. Заметки владельца не попадают и в рейс водителя.

**Альтернативы.** Открывать контакты только после подписания договора — отклонено: страница груза уже показывает контакты выбранному перевозчику с момента создания перевозки, а договор подписывается после согласования деталей погрузки, для которого контакты нужны.

**Последствия.** Новые выборки грузов для чужих компаний должны использовать `loadForViewer` или явный `select`; регрессионные тесты — `tests/integration/audit-stage-a.test.ts`.
